# 프로젝트 계획서 — 날씨 기반 AI 전자액자

- **과목**: 컴퓨터구조론
- **팀명**: 세모세모
- **조장**: 전성재 · **조원**: 한시원, 채성우

## 1. 개요
라즈베리파이 4B와 4.2인치 E-Paper(400×300, 흑백)로 전자액자를 만든다. 앱 설정에 미리 정해 둔 지역의 날씨를 API로 받아 오고, 그 날씨에 맞는 풍경을 AI가 흑백 펜화 스타일로 새로 그린다. 그림은 디더링을 거쳐 액자에 표시되고, 이 과정을 주기적으로 반복한다.

## 2. 목표
- 날씨(맑음·비·눈·흐림 등)와 시간대(아침·낮·저녁·밤)에 따라 그림 내용이 달라지는 액자
- 풍경 종류(산, 바다, 도시, 숲 등)는 무작위로 골라 매번 새로운 그림이 나오도록 함
- E-Paper는 전원이 꺼져도 화면이 유지되므로 저전력으로 상시 전시 가능

## 3. 시스템 구성 (처리 흐름)
1. 설정 파일(config)에서 지역 읽기
2. 기상청 API허브 ASOS 시간자료 호출 (시험 장소 군포 인근 수원 관측소 119)
3. 프롬프트 생성: 날씨 + 시간대 + 무작위 풍경 + "흑백 펜화 스타일"
4. 이미지 생성 API 호출 (OpenAI 이미지 API)
5. 영상처리: 400×300 리사이즈 → 대비 보정 → Floyd–Steinberg 디더링 → 날짜·기온 문구 표시
6. SPI로 E-Paper에 전송 (드라이버 IC SSD1683)
7. 스케줄러로 30~60분마다 반복

## 4. 컴퓨터구조론 연계 포인트
- SPI 통신과 GPIO 제어: RES, BUSY, D/C, CS 핀으로 SSD1683을 직접 제어
- 프레임버퍼 구조: 400×300 픽셀을 1비트로 표현해 15,000바이트 메모리 맵으로 변환
- E-Paper의 쌍안정(bistable) 특성과 전력 소비 분석
